Fingerprint Check

Fingerprint credentials are locked to the device that enrolled them. This step only works if you run it ON THE STUDENT'S OWN enrolled laptop/phone (hand it to them, or use a checkpoint device they previously registered on) — this admin computer cannot read a credential enrolled elsewhere.

Both face and fingerprint checks must pass before seat allocation. Seat allocation happens here on exam day only — clicking this approves the student and assigns their seat server-side, so candidates cannot know where they sit before being confirmed at the checkpoint.
